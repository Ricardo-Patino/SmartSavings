# SmartSavings - Proyecto 

SmartSavings es una aplicación móvil diseñada para ayudar a las personas a llevar un control detallado y personalizado de sus finanzas personales. Permitirá registrar ingresos y egresos, clasificar los gastos por categoría, visualizar estadísticas, establecer metas de ahorro y recibir alertas personalizadas. La aplicación busca ayudar al usuario a tomar decisiones financieras inteligentes, mediante una interfaz amigable y accesible. Además, la aplicación es comerciable, ya que responde a una necesidad real en la población: la falta de organización y control financiero. Se plantea un modelo freemium, en el cual se ofrecen funcionalidades de forma gratuita y herramientas avanzadas mediante suscripción o pago único.
